seminrExtras

Advanced modeling and analysis tools that extend SEMinR.

seminrExtras is a supplementary package for SEMinR — not a standalone package. It adds advanced tools for evaluating and validating PLS-SEM models estimated with SEMinR. Every function accepts an estimated seminr model object and returns results with print, summary, and plot methods.

It is also the home of the example models used in the Partial Least Squares Structural Equation Modeling (PLS-SEM) using R workbook (Hair et al., 2026).

What it provides

seminrExtras implements a range of methods for advanced PLS-SEM assessment:

  • Composite Overfit Analysis (COA) — detect observation-level overfitting via predictive deviance trees and parameter instability analysis (Danks, Ray, & Shmueli, 2024).
  • Congruence testing — bootstrapped congruence coefficient testing for construct validity (Franke, Sarstedt, & Danks, 2021).
  • Cross-Validated Predictive Ability Test (CVPAT) — compare a model’s predictive performance against benchmarks or alternative models (Liengaard et al., 2021; Sharma et al., 2023).
  • Predictive Contribution of the Mediator (PCM) — test whether a mediating construct improves out-of-sample predictive accuracy (Danks, 2021).
  • Importance-Performance Map Analysis (IPMA & cIPMA) — identify constructs that are both important and, via Necessary Condition Analysis integration, necessary (Ringle & Sarstedt, 2016; Hauff et al., 2024).
  • Necessary Condition Analysis (NCA & NCA-ESSE) — test whether predictors are necessary conditions for an outcome, complementing PLS-SEM’s sufficiency logic, with an effect-size sensitivity extension (Dul, 2016; Becker et al., 2026).
  • Confirmatory Tetrad Analysis (CTA-PLS) — empirically test whether a construct’s measurement model is reflective or formative (Gudergan et al., 2008).
  • Unobserved heterogeneity — detect latent classes via FIMIX-PLS (EM-based probabilistic segmentation) and PLS-POS (deterministic prediction-oriented segmentation).

Installation

Like SEMinR itself, seminrExtras is R-first: the R package is the authoritative implementation, and the Python and JavaScript/TypeScript ports maintain numerical parity with it (validated against R-generated golden fixtures). Each port consumes an already-estimated model from the matching-language SEMinR port, so it comes in the same three variants:

  • R — the authoritative package (on CRAN)
  • Python — a port on PyPI (experimental)
  • JavaScript / TypeScript — a port on npm (experimental)

Please note: The Python and JavaScript/TypeScript ports are experimental for now. The R package remains the authoritative implementation; if you run into a problem with a port, please report it on that port’s repository.

Install the released version from CRAN:

install.packages("seminrExtras")

Or install the development version from GitHub:

# install.packages("remotes")
remotes::install_github("sem-in-r/seminrExtras")

Then load it alongside SEMinR:

library(seminr)
library(seminrExtras)
  • Source: https://github.com/sem-in-r/seminrExtras
  • CRAN: https://cran.r-project.org/package=seminrExtras

A Python port with numerical parity to the R package, built on the seminr estimation engine. Requires Python 3.11+.

Experimental. Please report any issues on its GitHub repository.

Install from PyPI (pulls in seminr automatically):

pip install seminrExtras

Optional extras — matplotlib plots and pandas-friendly input:

pip install "seminrExtras[plot]"
pip install "seminrExtras[pandas]"

Then evaluate an already-estimated seminr model:

from seminrExtras import assess_cvpat

result = assess_cvpat(model, nboot=200, seed=123)
print(result)
  • Source: https://github.com/sem-in-r/seminrExtras-py
  • PyPI: https://pypi.org/project/seminrExtras/

A from-scratch TypeScript port that consumes an already-estimated model from @seminr/core, the TypeScript SEMinR estimation engine. Pure ESM, targeting Node 18+ / Bun.

Experimental. @seminr/extras is in early development (0.x) — please report any issues on its GitHub repository.

Install from npm (alongside the core estimation engine):

npm install @seminr/core @seminr/extras

Then assess an estimated SEMinR model:

import { assessCvpat } from "@seminr/extras";

const result = assessCvpat(model, { nboot: 2000, seed: 123 })!;
console.log(String(result));
  • Source: https://github.com/sem-in-r/seminrExtras-ts
  • npm: https://www.npmjs.com/package/@seminr/extras

Textbook demos

seminrExtras bundles the demo files for the PLS-SEM using R workbook (Hair et al., 2026). After loading the package, list and run them with demo():

demo("seminr-pls-cvpat", package = "seminrExtras")

Available demos include method walkthroughs (seminr-pls-cvpat, seminr-pls-pcm, seminr-pls-cipma, seminr-pls-coa, seminr-pls-nca, seminr-pls-fimix, seminr-pls-cta, seminr-pls-pos, seminr-pls-congruence) and per-chapter primers (seminr-primer-v2-chap2 through seminr-primer-v2-chap8).
